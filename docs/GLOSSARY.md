# Glossary

| Term | Meaning |
|---|---|
| **Anchor** | Evidence that an object existed by a given time (relay receipt, RFC 3161, OpenTimestamps) |
| **Apprentice** | A consultable model of a lineage; advises with provenance, never acts |
| **Attestation (`attest`)** | Signed statement of aggregate facts (e.g., calibration) over a committed set of objects |
| **Calibration** | Agreement between stated probabilities and observed frequencies |
| **Canon** | Versioned, curated set of cases with editors and an inclusion policy; preserves dissent |
| **Case** | One decision's lifecycle: open → prediction → decision → claims → (elicitation) → outcome |
| **Claim** | A pre-registered, probability-weighted, resolvable statement about what will happen if the chosen action is taken |
| **CID** | Content identifier (hash-based link) |
| **Commit (`commit`)** | Salted hash binding a sealed body to its plaintext |
| **Dissent** | A well-supported minority option/lineage surfaced alongside the majority |
| **Divergence (`diverge`)** | Record that B decided differently from A on a comparable situation: the "fork" |
| **Domain pack** | Data describing a profession's situation types, options, signals, claim templates |
| **Elicitation** | A short, well-timed question to surface what the practitioner noticed |
| **Lineage** | Graph of who learned from whom, plus divergences |
| **mnat / ppm** | milli-nats / parts-per-million integer encodings |
| **PIP** | Praxis Improvement Proposal |
| **PSP** | Praxis Sync Protocol |
| **Phronesis / episteme** | Practical wisdom vs. propositional knowledge (Aristotle) |
| **Reasoning Utility (RU)** | Held-out predictive lift from including an elicited reasoning |
| **Sealed body** | Encrypted body with a plaintext commitment |
| **Stakes weight (w)** | Consequence-based factor in the Surprise Engine |
| **Surprise (S)** | −ln q(chosen) under the apprentice's committed prediction |
| **Tacit knowledge** | Knowledge not (yet) articulated (Polanyi); here, the residual not predicted by stated knowledge |
